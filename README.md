# My Tasks

A small, responsive to-do list that runs in the browser. Add tasks, mark them complete, filter the list, delete individual tasks, or clear all completed tasks. Tasks persist in this browser using `localStorage`.

## Run it

Open `index.html` in a modern browser. No build step or external dependencies are required.

Your tasks are stored only in this browser on this device; clearing browser site data removes them. The app does not sync tasks between devices.
