# Al-iqbal-medressa

This repository includes two small browser apps with no build step or external dependencies:

- **To-do list:** open `index.html`. Tasks are saved in browser local storage.
- **Weather dashboard:** open `weather.html`. Search for a city or use the location button to see current conditions, an hourly forecast, and a seven-day outlook. It fetches forecast and geocoding data from the public [Open-Meteo API](https://open-meteo.com/) and does not require an API key.

For location access, open the page on HTTPS or localhost and allow the browser permission prompt. The dashboard starts with London if location access is not used.
